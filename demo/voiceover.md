# Voice-over script

Plain words, one block per scene. Scene 0 (title card) has no voice-over. The video's synthetic track is read from exactly this text; replace it with your own narration if you prefer.

## Scene 1: Upload the design

We start from the designer's Figma file for the Nissan Ariya landing page, as is. Attach it, say what we are building, and the studio reads the frames.

## Scene 2: Review the model

AI proposes the content model. A person decides. Here, two testimonial blocks look like one, so a single instruction merges them.

## Scene 3: Build

Days of modelling become a first draft in minutes. These are the generated files. Apply, and the admin appears, with the new content types and the sample pages.

## Scene 4: Rendered page

Content and design stay in step. This is the home page, rendered from those same blocks.

## Scene 5: Brief to draft

Marketers start from the brief they already have. Upload it, and a draft page appears, made only from approved page sections.

## Scene 6: Edit everywhere

Most CMS work is edits, not new pages. One instruction shows the change on every page as a diff, and the marketer accepts what they want.

## Scene 7: Pre-flight

Compliance issues are caught before review. Pre-flight flags a claim that is not approved, and one click swaps in the approved wording.

## Scene 8: Approve

Faster review, full audit trail. The approver sees what changed and a clean report, then approves. Only a person publishes.

## Scene 9: Other inputs and close

Start from a file, a screenshot, or a sentence. This is a prototype on one demo design. The next step is to try it on one of your own files.
